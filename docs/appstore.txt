PROMOTIONAL TEXT (max 170 characters)
-------------------------------------
Run classic CP/M software on your iPhone, iPad, or Mac. Experience WordStar, Zork, Turbo Pascal, and more with authentic Z80 emulation.


DESCRIPTION (max 4000 characters)
---------------------------------
Z80CPM brings the classic CP/M operating system to your iPhone, iPad, and Mac with a full Z80 processor emulator.

FEATURES

• Full Z80 Emulation - Accurate instruction emulation runs authentic CP/M software
• VT100 Terminal - ANSI escape sequence support for text adventures and productivity apps
• Multiple Disk Support - Mount up to 4 disk images simultaneously
• Download Disk Images - Fetch ready-to-run CP/M disk images from inside the app
• Choose Your RomWBW Release - Pick any release the published catalog offers, each with its own disks; a new release needs no app update
• Works Offline After Setup - Downloaded disk images are stored locally
• Native Mac Support - Runs natively on macOS via Mac Catalyst

CLASSIC SOFTWARE

Run the software that defined personal computing:
• Operating Systems: CP/M 2.2, CP/M 3, ZSDOS, NZCOM, ZPM3
• Word Processing: WordStar
• Programming: Turbo Pascal, Microsoft BASIC
• Text Adventures: Zork, Adventure, Hitchhiker's Guide to the Galaxy
• Text Editors: ZDE, TE, ED
• And thousands more CP/M programs

GETTING STARTED

1. Launch the app. The first launch needs an internet connection: it fetches the
   system ROM and two disk images - the Combo system disk and the games disk -
   and assigns them to Units 0 and 1 for you.
2. At the boot prompt, type 2 and press Enter. Units 0 and 1 are the RAM and ROM
   memory disks, so the first hard disk is Unit 2.
3. You'll see the A> prompt when CP/M is ready.
4. Settings has two dozen more disk images to download whenever you want them.

BUILT ON ROMWBW

This emulator is built on the RomWBW HBIOS platform, the same firmware used by real retro Z80 hardware projects. The system ROM and the disk images are built from the open-source RomWBW distribution and published by the developer at github.com/avwohl/romwbw_disks; the app downloads them from there and checks each one against its published checksum before use. They include freely distributable CP/M software. A first launch needs an internet connection to fetch them.

TECHNICAL DETAILS

• 80x25 character terminal display
• hd1k disk format - 8MB per slice, and the 49MB Combo image is six of them
• Hardware keyboard support
• Portrait and landscape orientation

Perfect for retrocomputing enthusiasts, computer history education, or anyone who wants to experience the operating system that launched the personal computer revolution.
